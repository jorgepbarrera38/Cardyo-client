# Cardyo – Frontend

Frontend desarrollado con Vue.js para un sistema de gestión de gimnasios, orientado a la administración de clientes, membresías, pagos y control de acceso.

La interfaz permite gestionar las operaciones administrativas del gimnasio y consultar información relacionada con la actividad de sus clientes.

## Funcionalidades principales

- Interfaz para el registro y administración de clientes.
- Configuración y gestión de tipos de membresías.
- Consulta de membresías activas e historial.
- Registro y seguimiento de pagos.
- Validación de ingreso mediante documento de identidad.
- Consulta de informes de pagos e ingresos.
- Visualización de información estadística del negocio.

## Tecnologías utilizadas

- **Framework:** Vue.js 2.
- **Navegación:** Vue Router.
- **Gestión del estado:** Vuex.
- **Consumo de API REST:** Axios.
- **Notificaciones:** Toastr.
- **Manejo de fechas:** Moment.js.
- **Gráficos:** Vue Trend Chart.
- **Componentes de selección:** Vue Select.
- **Calendario:** V-Calendar.

## Arquitectura

Este repositorio contiene la interfaz de usuario de Cardyo, desarrollada como una aplicación web que consume los servicios expuestos por el backend mediante una API REST.
